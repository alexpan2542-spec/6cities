# 城市遥感主动学习研究进展报告（含南京失败案例分析）

**对象：** 指导教师  
**日期：** 2026-08-08  
**课题方向：** 基于边界感知主动采样（BAMS）与原型扩张（PE）的城市三分类土地覆被制图校正  
**目标期刊（拟）：** *Remote Sensing*（MDPI）  
**数据基准：** ESA WorldCover（WC）三类别重映射（Class1≈建成，Class2≈非建成，Class3≈水体）  
**实验城市：** 武汉、合肥、南昌、长沙、南京（每城约 15,000 点）

---

## 1. 研究问题与方法主线

### 1.1 要解决什么问题
城市土地覆被产品（以 WorldCover 为代表）在 **建成/非建成边界** 上错误集中。随机或一般不确定性采样未必对准这些错误。希望用 **少量人工标注**，在固定标签预算下提升分类器相对 WC 的整体精度（OA）并降低边界混淆（Boundary Error, BE）。

### 1.2 方法链条（当前论文主叙事）
三步缺一不可：

1. **BAMS（Boundary-Aware Active Sampling）**  
   负责回答：**该标哪些点**（偏向边界/难例）。

2. **Confidence 过滤**  
   负责回答：**找到的点并非都该进入硬监督**。仅高置信（`high`）人标作为可靠种子；低/中置信硬写入训练会导致 **监督稀释（supervision dilution）**。

3. **PE（Prototype Expansion）**  
   负责回答：**如何用少量干净种子涨点**——在特征空间扩张原型，对低 margin 邻域赋予软标签再训练。

**一句话贡献定位：**  
不是“主动学习万能涨点”，而是证明：  
**BAMS 解决选点；Confidence 解决用点；PE 解决扩点。**  
并给出该方法 **何时有效、何时因参考标签冲突而失效** 的适用边界（以南京为 failure case）。

---

## 2. 五城主结果（方法有效性）

评测协议：与原始 WorldCover `Class` 做逐点对比；多种子（通常 5 seeds）取均值。

### 2.1 总体结论
| 环节 | 现象 |
|------|------|
| 仅 BAMS150 写入训练 | 边界错误命中率高，但 OA **几乎不涨甚至略降**（监督稀释） |
| BAMS + PE | 多数城市 OA **约 +0.9～1.8 pp**，BE 明显下降 |
| 五城平均 | PE 量级大约 **+1 pp OA** 左右（含南京会被拉低） |
| 去掉南京的四城 | 平均增益更高（约 **+1.3～1.4 pp** 量级） |

### 2.2 分城 PE 增益（Phase-1 指纹，相对 Baseline）

| City | Base OA | Base BE | BAMS ΔOA | PE ΔOA | PE ΔBE |
|------|---------|---------|----------|--------|--------|
| Wuhan | 0.910 | 297 | +0.03 pp | **+1.82 pp** | −79 |
| Changsha | 0.930 | 234 | +0.11 pp | **+1.52 pp** | −58 |
| Nanchang | 0.912 | 206 | +0.07 pp | **+1.35 pp** | −41 |
| Hefei | 0.932 | 240 | −0.06 pp | **+0.87 pp** | −43 |
| **Nanjing** | **0.903** | **304** | **−0.27 pp** | **+0.36 pp** | −18 |

**读法：** 主方法在四城成立；南京是明显异常/失败样本，必须单独解释，不能藏进平均里假装五城全胜。

### 2.3 Help / Hurt（相对 Baseline 预测翻转）

| City | BAMS help/hurt | PE help/hurt |
|------|----------------|--------------|
| Wuhan | 1.14 | **2.06** |
| Changsha | 1.34 | **2.12** |
| Nanchang | 1.18 | **1.64** |
| Hefei | 0.92 | 1.47 |
| **Nanjing** | **0.66（hurt≫help）** | **1.14（勉强）** |

南京在 BAMS 阶段就已经对 WC 评测产生 **净伤害**；PE 只能部分挽回，无法达到其他城的增益量级。

## 3. 南京为什么不一样（核心讨论）

### 3.1 不是单一原因，而是耦合条件
更准确的表述：

> 南京失败，不是因为 PE 算子坏了，而是 **「边界人标 ↔ WC 金标准」冲突** 与 **场景难度高** 耦合后，在 **以 WC-OA 为唯一分数** 的协议下表现为方法失效。

需要同时看到三点：

1. **最难基线：** Base OA 最低、BE 最高、低 margin 池最大（Phase-1 多项排名 #1 最差）。  
2. **纠错在 WC 试卷上净负：** BAMS help/hurt = 0.66，BAMS ΔOA 最差。  
3. **PE 抬不动到成功量级：** 仅约 +0.3～0.4 pp。

### 3.2 重要澄清：不能说“只有南京 WC 最差”
同一 BAMS150 协议下，**人标 ≠ WC** 比例：

| City | Human≠WC | C1↔C2 对调率 |
|------|----------|--------------|
| Hefei | **81%** | 75% |
| **Nanjing** | **68%** | 51% |
| Wuhan | 58% | 49% |
| Changsha | 53% | 34% |
| Nanchang | 45% | 28% |

合肥人–WC 不一致甚至更高，但基线容易且 PE 仍涨。  
因此：**“和人不一致”必要但非充分**；南京独特在于 **高冲突 + 最难基线 + BAMS 在 WC 上净伤害**。

### 3.3 给老师的直观类比
- 五城都在改卷（人标），但考试仍按 WC 阅卷。  
- 其他城：改动多数也让 WC 分数变好 → PE 扩张后 OA 上升。  
- 南京：改动经常是“目视对、WC 仍算你错” → 越跟人学，越可能在 WC 考试上被扣分。

## 4. 南京深入诊断（本阶段已完成工作）

### 4.1 BAMS150 重标注 + Confidence
- 对南京 BAMS150 做了更规范的目视与 **Confidence（high/med/low）**。  
- 经验规则逐步固化：成片建成→1；稀疏农村屋顶点缀农田→2；路主体→1、路缘植被主导→2；分不清标低置信，不硬翻。

**消融（南京，WC-OA）：**

| Method | ΔOA vs Baseline |
|--------|-----------------|
| 直接写全部人标（RF/BAMS） | 负或接近 0 |
| PE（全部人标） | ~+0.21 pp |
| **PE（仅 high）** | **~+0.33 pp** |
| PE（high+med） | ~+0.17 pp（不如 high-only） |

→ 支持主故事：**不是标得越多越好，而是高置信种子更重要。**

### 4.2 Round2：再标 50 个 C1–C2 软边界
从 15k 中筛选未入 BAMS、低 margin、C1–C2 易混点，空间分散后人工标注 50 点。

| 项 | 结果 |
|----|------|
| Confidence | high 33 / med 14 / low 3 |
| 相对 WC 翻转 | **37/50（74%）** |
| PE 仅用 Round2 high（33 点） | **+0.40 pp OA，BE −16.6** |
| PE：BAMS high ∪ Round2 high | +0.33 pp（未再提升） |
| 并入 med | 略降 |

**含义：**  
针对性高置信边界种子 **本身有效**；与旧种子简单合并 **不保证叠加增益**；继续堆数量无法把南京修成“成功城”。

### 4.3 双轨评测：WC-OA vs Human-OA（严格 hold-out）
池：BAMS high ∪ Round2 high = **106** 点（相对 WC 翻转约 **70%**）。  
每 seed：**63 训练种子 / 43 只测不训**。  
Hold-out 人标与 WC 一致率仅约 **35%**。

| Method | WC-OA | Human-OA（hold-out） |
|--------|-------|----------------------|
| Baseline MLP | 0.909 | 0.665 |
| PE（正当 hold-out，按 Human 选 K） | 0.902（略降） | **0.688（+2.3 pp）** |
| PE（按 WC 选 K） | 0.907 | 0.595（Human 变差） |
| RF 刷 WC+人标种子 | 0.902 | 0.428（更差） |
| PE 泄漏对照（测试点也进种子） | 0.903 | 0.837（**虚高，不可用**）|

**结论（对老师很关键）：**
1. **换人标评测也不能 magically 翻盘**（正当协议下仅约 +2 pp Human-OA）。  
2. “刷 WC 再用人标测”若发生泄漏会看起来很好——必须严格 hold-out。  
3. **两个金标准互相打架**：跟人对齐一点，WC-OA 就掉一点。  
4. 根子仍是：15k 绝大多数仍是 WC 监督；稀疏散点人标撬不动全局，且冲突点上目标不一致。

### 4.4 High × 3×3 WC 邻域实验
数据：BAMS150 的 GEE 导出 8 邻域 WC 标签（`has_C1_nb8`, `suggest_C_if_uncertain` 等）。Round2 尚无邻域导出。

**诊断（73 个 high）：**
- 与 WC 翻转：**62%**  
- 与邻域 suggest 一致：**仅 38%（28/73）**  
- Human=1 但邻域无建成（孤立建成）：**15/31**  
- Human=2 却邻域有建成：约 **67%**

**PE：**

| Method | 种子数 | ΔOA | ΔBE |
|--------|--------|-----|-----|
| PE_high（全部 high） | 73 | +0.33 | −14 |
| **PE_high_nb_agree（人=suggest）** | **28** | **+0.43** | **−20** |
| PE_high_c1gate / iso2 | — | 更差或无增益 | — |

**含义：**  
3×3 邻域 **不能当真理去改人的高置信标签**（一致率太低）；当作 **过滤器**（只留人与 WC 邻域同向的种子）时，WC-OA 略好。再次证明：能抬 WC-OA 的是冲突较小的子集；邻域启发式与高置信目视系统性拧着。

### 4.5 其他已排除/弱效果方向（简述）
- 盲用邻域 suggest 覆盖 low/med：WC-OA 可虚高，但目视审计显示语义不可靠（人更常对）。  
- 难例硬翻邻居训练、冲突降权等：无法接近“修好南京”。  
- 直接 RF 写入人标：通常伤害 WC-OA。

## 5. 当前可写成的论文贡献（建议表述）

### 5.1 正面贡献
1. **边界感知主动采样（BAMS）** 对准城市建成边界错误。  
2. 揭示并验证 **supervision dilution**：BAMS 找得到错，不等于 150 点直接训练能涨 OA。  
3. 提出 **Confidence 过滤 + PE** 作为固定预算下的有效用法：  
   **选点（BAMS）≠ 用点（Confidence）≠ 扩点（PE）**。  
4. 多城实验显示：在 WC 评测与人标大体同向的城市，PE 可带来约 **+1 pp** 量级稳定增益（四城更高）。

### 5.2 方法适用边界（同样是贡献）
5. 以南京为 **failure case**：当边界参考冲突与高难度耦合，且以 WC-OA 为唯一目标时，BAMS+PE **无法大幅提升**。  
6. 用 help/hurt、双轨评测、Round2、3×3 邻域诊断支撑机制解释，避免“藏起失败城”。

### 5.3 建议避免的过强措辞
- 不要写“大大提高 / 证明南京 WC 整体不可用”。  
- 宜写：  
  - *consistent improvement under a fixed labeling budget*  
  - *reference conflict under WC-referenced evaluation*  
  - *necessary but not sufficient*（相对“仅有人–WC 不一致”）

## 6. 投稿可行性（如实判断）

| 项目 | 判断 |
|------|------|
| 与 *Remote Sensing* 匹配度 | 高（城市制图 + 主动学习 + 产品标签） |
| 当前完整度 | **可冲，不算稳中**；更可能 major revision |
| 主结果幅度 | ~+1 pp OA：站得住，不惊人；必须靠机制与公平基线撑住 |
| 最大审稿风险 | （1）增益偏小；（2）WC 自评循环；（3）新颖性需落在“置信过滤+适用边界”；（4）合肥高冲突却成功需解释清楚 |

**补 Confidence 到其他四城的意义：**  
即使平均仍约 +1%，价值主要在 **五城统一消融故事**（PE_all vs PE_high），而不是指望再涨很多点。

## 7. 建议的下一步（按性价比）

### 7.1 为钉死南京机制（优先）
1. **第二参考图交叉验证**（强烈推荐）  
   五城 BAMS150 上叠加 Dynamic World / ESRI：看「人≈第二产品≠WC」是否南京最高。  
2. **分层评测**  
   测试点分 `人=WC` / `人≠WC`，展示 PE 在两层上的背离。  
3. **失败条件列联表**  
   把 disagree × Base难度 × help/hurt → PE 弱，收掉合肥反例。

### 7.2 为抬投稿把握（主结果）
4. 其他四城补 **Confidence**，统一 `PE_all / PE_high / PE_hm` 消融。  
5. 补强公平基线：random / margin / entropy 等同预算对比 + 显著性/置信区间。

### 7.3 可选
6. Round2 的 3×3 邻域 GEE 导出（完整性）。  
7. 非 BAMS 独立人标测试集（更干净的 Human test）。

---

## 8. 总括（给老师的三句话）

1. **方法主线已清楚：** BAMS 找边界点；不能全用；只用 high confidence 做 PE，才能在多数城市稳定涨约 1 个百分点 OA，并降边界错误。  

2. **南京是有价值的失败案例：** 不是算子偶然失灵，而是在 WC 金标准下，边界人标与产品标签冲突 + 城难，导致 BAMS 净伤害、PE 天花板很低；换人标 hold-out 也只能微涨，说明不是“换个测试就会好”。  

3. **现阶段适合收束成 *Remote Sensing* 向稿件：** 主结果讲四城/五城有效条件，Discussion 用南京划清适用范围；若再补第二参考图与四城 Confidence，机制与审稿说服力会明显增强。
