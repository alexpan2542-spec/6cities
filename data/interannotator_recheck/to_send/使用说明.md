# 边界点独立复核 — 使用说明

## 你要做什么

`annotator_A/` `annotator_B/` `annotator_C/` 三个文件夹下各有 6 个城市的 CSV，
每城 20 个点（Wuhan / Hefei / Nanchang / Nanjing / Changsha / Hangzhou）。
每人只需要处理**自己名字对应的那一份文件夹**（A / B / C 各拿一份，互相独立完成，
完成前请不要跟另外两人讨论或对答案）。

对每一行，根据 `lat` / `lon` 在 Sentinel-2 影像（或 Google Earth / 天地图等高分辨率
底图）上定位到这个点，独立填写三列：

| 列名 | 填什么 |
|---|---|
| `My_Class` | `1` = 建成/建筑用地，`2` = 非建成（植被、裸地、农田等），`3` = 水体 |
| `My_Confidence` | 自己对这个判断的把握程度：`h`(高) / `m`(中) / `l`(低) |
| `My_Scene` | 用几个字描述这个点周边是什么场景，比如「水稻田」「道路边缘」「建筑屋顶」「水陆交界」——用你自己的话写，不用套用固定格式 |

**其余列（CheckID / Original_ID / lat / lon）不要改动。**

## 重要：这次是独立盲标，不是核对

- 请**不要**查阅任何已有的分类结果、标注表或原始数据——这些点的"标准答案"你现在看不到也不需要看，独立判断即可。
- 请**不要**互相讨论或对照彼此的判断，三人的结果需要是各自独立得出的。
- 拿不准的点正常给 `l`（低置信度），不用纠结，这本身就是要收集的信息。

## 完成后

填完直接把整份 CSV（6 个城市）发回给我，文件名不用改。每人预计 20×6=120 个点，
大概 1 小时左右能做完，可以见缝插针地做，不用一次性做完。

谢谢！
